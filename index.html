Qué es SafePlant

SafePlant es un sistema de monitoreo y prevención de riesgos diseñado para el control de la seguridad y la contaminación ambiental en plantas industriales. Supervisa continuamente las condiciones del entorno y actúa antes de que un riesgo afecte a los operarios.

01

Control ambiental

Mide de forma constante la calidad del aire y el nivel de ruido en las zonas de trabajo.

02

Seguridad del personal

Identifica la presencia de operarios en zonas críticas para evaluar su nivel de exposición.

03

Respuesta automática

Activa extractores, sirenas preventivas y mamparas acústicas sin intervención manual.

Monitoreo en tiempo real

Cómo responde el sistema

Tres etapas continuas que transforman una lectura de sensor en una acción de protección real.

  1. 01

    Detectar

    Los sensores recopilan datos ambientales y detectan la presencia de personal.

  3. 02

    Analizar

    El sistema analiza las mediciones en tiempo real y determina si existe una condición peligrosa.

  5. 03

    Actuar

    Cuando se supera un umbral de seguridad, el sistema activa automáticamente los mecanismos correspondientes.

De la detección a la acción automática

Cada mecanismo se activa según el tipo y la severidad del riesgo detectado, sin esperar intervención humana.

ACTIVO

Ventilador de extracción

Activación automática ante niveles elevados de CO₂.

STANDBY

Bocina preventiva

Alerta inmediata cuando un operario se encuentra expuesto a una condición peligrosa.

DISPONIBLE

Mamparas acústicas

Aislamiento acústico complementario ante niveles excesivos de ruido.

MONITOREANDO

Alerta al sistema

Registro y comunicación del evento detectado.

Arquitectura técnica

Cuatro capas que conectan los sensores de planta con los equipos de supervisión y gobernanza, desde el dato crudo hasta la decisión.

01

Dispositivos embebidos

Microcontroladores ESP32 conectados a sensores de CO₂, ruido y presencia, junto a los actuadores físicos que ejecutan la respuesta en campo.

ESP32 Sensor CO₂ Sensor de ruido Sensor de presencia Actuadores físicos
02

API Gateway

Un API Gateway centraliza las lecturas de los dispositivos embebidos, procesa las reglas de riesgo y conserva los datos en una capa de persistencia de contingencia si se pierde la conexión con la nube.

Persistencia de contingencia
03

Plataforma en la nube

Una API REST recibe y expone la información de planta, respaldada por una base de datos relacional que almacena mediciones, eventos y el historial de respuestas automáticas.

API REST Base de datos relacional
04

App móvil de operación

Monitoreo, control operativo y configuración técnica del sistema, pensada para el supervisor de seguridad en campo.

App web de gobernanza

Métricas y el historial de eventos, orientada al encargado de planta.
